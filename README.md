
# 💧 AquaWise — Water Footprint Calculator

AquaWise is a responsive frontend web application that estimates daily household water usage and encourages water-saving habits.

## 🌿 Features

- Calculate estimated daily water usage.
- View weekly and monthly estimates.
- See a breakdown of shower, toilet, laundry, and dishwashing usage.
- Explore simple water-saving tips.
- Responsive design for desktop and mobile.
- Reset the calculator to its default values.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.
4. Enter your water usage values.
5. Click Calculate My Water Usage to see the results.

## 🧮 Calculation Method

The application uses configurable example assumptions:

- Shower: 9 litres per minute.
- Toilet: 6 litres per flush.
- Laundry: 60 litres per load.
- Dishwashing: user-provided litres per day.

Daily usage is calculated from the values entered in the form. Weekly estimates multiply daily usage by 7, and monthly estimates multiply it by 30.

These are illustrative estimates, not measured consumption. Actual water usage varies depending on appliances, water pressure, and personal habits. The calculator covers selected direct household uses rather than a complete water footprint.
